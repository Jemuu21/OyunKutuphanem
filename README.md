# Oyun Kütüphanem

Steam ve Epic Games oyunlarını tek bir koleksiyon rafında gösteren Windows programı.

**İndirmek için:** sağ taraftaki **Releases** bölümünden en son `OyunKutuphanemKurulum.exe` dosyasını indirip çalıştır.
Windows "bilgisayarınızı korudu" derse **Ek bilgi**, sonra **Yine de çalıştır** de.

Program kurulduktan sonra yeni sürümleri kendisi bulur ve güncellenir.
